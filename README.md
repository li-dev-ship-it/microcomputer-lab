# 微机实验报告资料

本仓库为私人实验资料库，供 Codex 云端继续协助填写实验报告。不得改为公开仓库。

## 资料目录

- `实验报告照片/`：28 张报告照片，是待填写题目的依据。
- `实验程序/微机/`：实验 1～7 的汇编源代码、Keil 工程、编译产物、操作说明及参考文档。
- `指导书资料/`：单片机实验指导书 PDF。
- `原始资料清单.json`：全部 291 个原始文件的相对路径、字节数及 SHA-256，用于核对完整性。

## 接续任务要求

1. 使用中文。用户会逐个询问实验，按报告照片的原题顺序给出适合填写空白的答案。
2. 重点参考实际 `.asm` 程序，同时对照指导书、操作说明、实验内容、要求和实验台型号。不得仅凭通用知识猜测。
3. 文件夹编号与题目对应关系须结合内容核实，不能仅凭文件名判断。
4. 程序功能、寄存器、执行过程和结果应具体对应代码；程序推导与实测现象分开说明，不编造实测数据。
5. 遇到流程图题目，应自主使用可用插件或绘图工具生成并展示成图，不仅提供流程图代码。如工具不足应明确告知。
6. 关注 `实验程序/微机/5.2和6.4有问题需要自己搞.txt` 的提示；涉及相关程序时核对其正确性。
7. 保留原始照片、文档和代码；未经用户要求，不修改源程序，不批量填写所有实验。
8. 旧文本可能采用 GBK 编码；出现乱码应检查编码，不覆盖原文件。
